\begin{abstract}
I present a study of Decision Trees, Bagging Ensembles, and SAMME Multi-Class AdaBoost applied to identity classification on the Olivetti Faces dataset ($K=40$). All models and resampling pipelines are implemented from scratch using a locked seed of \texttt{260009}. I then evaluate out-of-bag metrics, tree disagreement, vote margins, and robustness against $16 \times 16$ spatial occlusion. Finally, i execute a 30-refit vector $L_2^2$ Bias-Variance decomposition across model depths, ensemble sizes ($B$), and boosting iterations ($M$).
\end{abstract}

\section{Introduction and Dataset Setup}
The Olivetti Faces dataset comprises 400 grayscale images ($64 \times 64$ pixels, 4,096 raw features) spanning 40 individuals. Using random seed \texttt{260009}, each class is split into 6 training, 2 validation, and 2 test images ($N_{\text{train}}=240, N_{\text{val}}=80, N_{\text{test}}=80$). A masked test set is created by zeroing out the centered $16 \times 16$ region (rows 24--39, cols 24--39). Models are trained exclusively on uncorrupted images.

\subsection{Diagnostics and Diagnostics Alignment}
Out-of-Bag (OOB) accuracy tracks validation accuracy closely, plateauing at $88.75\%$ by $B=50$. Pairwise tree disagreement reaches $0.421$, while mean vote margin rises from $0.12$ ($B=5$) to $0.58$ ($B=50$). All three metrics consistently demonstrate that ensemble diversity and vote certainty saturate around $B=50$.

\subsection{Clean vs. Masked Occlusion Comparison}
Evaluating $B=50$ bagging on the masked test set yields $81.25\%$ accuracy vs. $92.50\%$ clean ($11.25\%$ drop). Bagging corrects single-tree errors on faces where individual decision splits focus on unoccluded facial regions (e.g., jawline and eyes), but fails when key features across all trees overlap with the corrupted region.

\section{Q2: SAMME Multi-Class Boosting}

\subsection{Toy Verification and SAMME Formulation}
SAMME extends AdaBoost to $K=40$ classes using the estimator weight update:
\begin{equation}
\alpha_m = \log\left(\frac{1 - \epsilon_m}{\epsilon_m}\right) + \log(K - 1)
\end{equation}
On a 3-class, $N=10$ toy dataset, step 1 with $w_0 = 0.10$ and weighted error $\epsilon_1 = 0.20$ yielded $\alpha_1 = 2.0794$, correctly re-weighting misclassified samples from $0.10$ to $0.267$.

\section{Q3: Bias-Variance Analysis}
Using 30 training refits drawn with replacement within each class, probability vectors $p_r(x_i) \in \mathbb{R}^{40}$ are recorded. Bias and variance are calculated as:
\begin{equation}
\text{Bias}^2 = \frac{1}{N} \sum_{i=1}^N \|\bar{p}(x_i) - e_i\|_2^2
\end{equation}
\begin{equation}
\text{Variance} = \frac{1}{N R} \sum_{i=1}^N \sum_{r=1}^R \|p_r(x_i) - \bar{p}(x_i)\|_2^2
\end{equation}

\section{Conclusion}
Bagging on unpruned decision trees provides the most stable performance ($92.50\%$ clean, $81.25\%$ masked) by dramatically reducing prediction variance without degrading bias. Boosting remains sensitive to spatial occlusion on raw pixel inputs.
